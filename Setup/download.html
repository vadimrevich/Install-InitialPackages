Install Initial Packages Setup

Описание программы.

Программа предназначена для первичной установки необходимых дополнений операционной системы после её установки на компьютер или виртуальную машину. Подходит для версий операционной системы Microsoft Windows 7Sp1 — 11 и Microsoft Windows 2008 R2 — 2025 Desktop Editions. Без установки этой программы дальнейшая настройка Microsoft Windows проходит с затруднениями. Программа устанавливает следующие компоненты:

  • Сертификаты Microsoft, NIT и МинЦифры России.
  • Исключения антивируса на пользовательские папки. Примечание. Если системе не удалось самостоятельно установить исключения, она запросит их установку в ручном режиме, приведя инструкции по установке. Не используйте продукты New Internet Technologies, Inc. без установки этих исключений!
  • Установка MSVC Redistrubutable Bundle AIO (необходима для запуска современных программ, созданных в Visual C++ 2015+).
  • Установка .Net Framework 4.8.1. Developer (требуется для большинства программ Windows).
  • Менеджер пакетов Chocolatey (позволит быстро «починить» систему и установить дополнительное программное обеспечение). Незаменимый пакет для администраторов и разработчиков.
  • Загрузка образа диска с дальнейшими программами установки.

Программа запускается в виде приложения-формы на Microsoft HTA. Поэтому для своей работы требует наличие в системе компонентов Internet Explorer и WSH. В редакциях Windows Server Core это не так, и пакет работает в ней со многими ограничениями (скрипты нужно запускать без графического интерфейса). Необходимо только наживать кнопки и отвечать на простые вопросы.

Отдельный вопрос — ручная установка исключений. Не смотря на наличие подробной текстовой и видео инструкций, ручная установка исключений может вызвать затруднения у пользователей. Обратитесь за помощью к более опытным пользователям. Помните, бесконтрольная установка исключений снижает вашу безопасность, хотя это единственный путь противодействия обструкции со стороны Microsoft.

  • Ссылка на загрузку программы: InstallInitialPackagesSetup.exe — ссылка на загрузку файла для инсталляции пакета.

Не забудьте разблокировать файлы после загрузки перед запуском на исполнение!

Действия после загрузки скрипов

Перед началом загрузки скриптов необходимо открыть командную строку powershell и разблокировать запуск скриптов. Для этого необходимо:

  • Нажать сочетание клавиш Win+R.
  • Набрать в командной строке powershell и нажать сочетание клавиш Ctrl+Shift+Enter.
  • Запуститься консоль Powershell в режиме администратора. Примечание. Если возникнет ошибка и консоль не откроется в режиме администратора, дальнейшие действия не предпринимайте. По-видимому, Ваша учётная запись не входит в группу администраторов, а без этого работа с админ-паком утрачивает смысл.
  • Введите в консоли Powershell (можно копированием и вставкой с этого сайта) следующие команды и нажмите Enter:

    • Set-ExecutionPolicy -ExecutionPolicy Unrestricted

    Set-ExecutionPolicy -ExecutionPolicy Unrestricted -Scope CurrentUser

  • После этого переходите к выполнению загруженных скриптов.

После загрузки скрипта или программы разблокируйте их. Для разблокировки файлов средствами графического интерфейса используйте следующее. Щёлкните правой клавишей мыши по загруженному в папку «Загрузки» текущего пользователя файлу. Необходимо выбрать в пункте Свойства на вкладке Общие действие Разблокировать -> Ok.

Затем запустите его щелчком правой клавишей мыши на его имени, выберите пункт выполнить с помощью Powershell для *.ps1 скриптов или Запуск от имени администратора для других исполняемых файлов. Соглашайтесь со всеми сообщениями в диалоговых окнах. Программа автоматически повышает свои привилегии.

Ошибки при выполнении скриптов и программ, загруженных с данной страницы.

  • Ошибка установки программы в Microsoft Windows 7 Starter и некоторых других часто связана с отсутствием в системе установленного Service Pack 1 for Windows 7/Windows Server 2008 R2. Для начала работы необходимо установить Service Pack 1. Примечание. В Windows 7 Starter Edition этот сервис-пак не устанавливается, поэтому данная программа для неё не применима. Лучше всего загружать и устанавливать операционную систему с интегрированным сервис-паком.
  • Ошибка при установке пакета Chocolatey в Microsoft Windows 7 Отсутствуют необходимые файлы. Ошибка возникает из-за отсутствия в системе поддержки шифрования TLS 1.2. Из-за этого также не устанавливаются некоторые сертификаты. Исправление: Прочитайте внимательно статьи: статья 1, статья 2. Установите обновление с этой страницы и фикс с этой страницы. После чего перезагрузите компьютер. Примечание старая версия Internet Explorer не даст вам загрузить эти обновления непосредственно в Windows 7. Загрузите программы на другом компьютере, и перенесите файлы на флешке на целевой компьютер с Windows 7.
  • Ошибка при установке последней версии .Net Framework 4.8.1 «Версия файла не поддерживается». Microsoft .Net Framework устанавливается только на операционные системы Windows 10 и Windows 11 последних версий, и недоступен для более ранних версий Microsoft Windows. К тому же есть ограничения на версию «Developer Edition». Исправление: Перейдите сразу к установке пакета Chocolatey. Он загрузит последнюю из доступных версию .Net Framework.
  • Привилегии в программе не повышаются. При запуске появляется окно с предложением запустить программу от другого пользователя. Причина. Чаще всего такое поведение программы наблюдается в корпоративных сетях, когда пользователю операционной системы запрещено устанавливать программы и вмешиваться в настройки операционной системы. Иногда такую настройку включает приходящий системный администратор. Исправление. Запустите программу в учётной записи, допускающей повышения привилегий.
  • Примечание. Все эти ошибки пропадают после обновления компонентов операционной системы Microsoft Windows. Однако принятие решения об установки обновлений может только служба поддержки. Поэтому среди советов нет банального: обновите Windows, — а вместо этого предложено всеми возможными путями отправить файл в техподдержку New Internet Technologies.
